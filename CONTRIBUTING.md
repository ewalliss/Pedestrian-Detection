# Contributing

This repository is a public demo clone of the private `pedestrian_detection` repo.
Please keep contributions small, public-safe, and relevant to the demo surface of this repository.

## Issues

Open an issue for bugs, documentation fixes, or small improvements that are useful in the public demo.

## Pull requests

- Keep changes focused and easy to review.
- Avoid adding private or internal-only assets, notes, or tooling.
- Prefer updates that improve the public demo, setup flow, or reproducibility.

For larger changes, start with an issue so the scope is clear before you open a PR.
